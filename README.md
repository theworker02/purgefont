# purgefont

Purge filesystem font paths across POSIX and Windows conventions.

**Site:** https://theworker02.github.io/purgefont/

## Install / run

```bash
git clone https://github.com/theworker02/purgefont.git
cd purgefont
node src/cli.js
node --test
```
